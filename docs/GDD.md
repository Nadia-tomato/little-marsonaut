# MARS CREW — Game Design Document

> 本文件是 MARS CREW 後續開發的主要需求來源。遊戲機率、資源數值與事件效果是教育遊戲的平衡參數，不是 NASA 實測數據；尚未定義的內容均標記為「待平衡測試」。

## 1. 遊戲概述

| 項目 | 規格 |
| --- | --- |
| 名稱 | MARS CREW |
| 類型 | 單人火星基地生存與科學探索教育遊戲 |
| 目標玩家 | 7–12 歲 |
| 平台 | 網頁，支援桌機與手機 |
| 遊戲長度 | 最多 20 Sol |
| 預估遊玩時間 | 12–15 分鐘 |
| 視角與操作 | 2D 俯視角火星基地；優先使用點擊工作站操作 |
| 核心體驗 | 在有限電力與基地資源下維持生存，並派遣探測車收集地質樣本 |

## 2. 設計目標與範圍

玩家扮演火星基地任務成員，必須在 20 Sol 內管理基地的氧氣、水、食物與電力，同時安排探測車進行科學探索。探索會消耗電力，基地生存也需要電力，因此玩家要在「維持生存」與「追求科研分數」之間做出簡單、可理解的決策。

### 明確不包含的內容

- 單人遊戲，不建立多人房間或聊天功能。
- 手機優先，不要求先完成 WASD 角色移動。
- 不製作完整野外探索地圖。
- 不加入水冰採集；水只能使用庫存並在 Sol 10 補給。
- 只種植番茄。
- 不加入外星生物攻擊。
- 遊戲虛構的重大發現不可描述為 NASA 已證實的外星生命。

## 3. 核心遊戲循環

1. 查看當前 Sol、基地資源、事件與探測車狀態。
2. 點擊工作站進行能源、農業或探勘操作。
3. 選擇是否派遣探測車；每個 Sol 最多探勘一次。
4. 結束 Sol，套用資源消耗、發電、作物與環境事件結果。
5. 持續至 Sol 20、發生緊急中止，或觸發重大科研發現。

## 4. 資源系統

四種主要資源都使用 0–100 的血條式介面。

| 資源 | 初始值 | 主要用途 | 補充規則 |
| --- | ---: | --- | --- |
| 氧氣 | 70/100 | 維持基地與人員生存 | 由能源站水電解製氧；具體消耗與轉換效率：待平衡測試 |
| 電力 | 70/100 | 基地運作、探索與工作站操作 | 太陽能發電；沙塵暴會降低發電；具體數值：待平衡測試 |
| 水 | 100/100 | 農業與水電解製氧 | 不可透過採礦補充；只使用原有庫存，Sol 10 補給時恢復至 100 |
| 食物 | 60/100 | 維持基地與人員生存 | 農業站種植、澆水、採收番茄；Sol 10 補給時恢復至 100 |

所有每日消耗、工作站操作成本、最低警戒值與資源耗盡後的恢復規則，若本文件未明確指定，皆為「待平衡測試」。

## 5. 工作站

### 5.1 能源站

- 太陽能發電。
- 電力分配。
- 水電解製氧。
- 探測車充電。
- 操作應清楚顯示消耗的水、產生的氧氣或改變的電力。

### 5.2 農業站

- 種植番茄。
- 為番茄澆水。
- 採收番茄以補充食物。
- 生長所需 Sol、每次澆水成本、收成量與同時可種植數量：待平衡測試。

### 5.3 探勘站

- 選擇探測車電池格數並派遣探測車。
- 顯示 NASA 火星照片與科普內容（接入真實資料前使用明確標示的暫存內容或空狀態）。
- 顯示隨機地質樣本結果與科研分數。

## 6. 探測車系統

- 電池採用 0–5 格的離散值。
- 出發時電池格數會影響樣本發現機率。
- 每個 Sol 最多探勘一次。
- 電量不足時無法派遣；0 格不可出發。
- 受到太陽高能粒子事件影響時，玩家可以冒險派遣，但可能導致探測車停用 1–2 Sol。
- 充電成本、每格所需電力、停用期間的顯示方式：待平衡測試。

## 7. 地質樣本與科研分數

### 7.1 基準機率

| 結果 | 基準機率 | 科研分數 |
| --- | ---: | ---: |
| 無發現 | 30% | 0 |
| 玄武岩 | 30% | 10 |
| 含鐵礦物 | 15% | 15 |
| 含水礦物 | 9% | 30 |
| 其他特殊地質樣本 | 15% | 25 |
| 重大特殊發現 | 1% | 特殊結局 |

### 7.2 電量修正

| 出發電池 | 樣本發現機率修正 |
| --- | --- |
| 4–5 格 | 完整基準機率 |
| 2–3 格 | 樣本發現機率乘以 0.75 |
| 1 格 | 樣本發現機率乘以 0.5 |
| 0 格 | 不能出發 |

電量修正後減少的機率全部歸入「無發現」，以確保總機率為 100%。具體亂數抽樣方式與 UI 呈現：待平衡測試。重大特殊發現是遊戲虛構的特殊結果，不得呈現為 NASA 已證實外星生命。

## 8. 環境事件

以下是簡化的教育遊戲機制，用來教學風險與資源管理：

| 事件 | 遊戲效果 | 待定內容 |
| --- | --- | --- |
| 沙塵暴 | 降低太陽能發電 | 發生條件、持續時間、發電降低比例：待平衡測試 |
| 太陽高能粒子事件 | 玩家可冒險派遣探測車，但可能使探測車停用 1–2 Sol | 發生條件、停用機率、警示呈現：待平衡測試 |

未來可加入五級遊戲輻射警戒；其分級、效果與教育文字目前均為待定，且必須與真實 NASA 資料清楚區分。

## 9. Sol 與事件流程

- 遊戲從 Sol 1 開始，最晚進行至 Sol 20。
- 每個 Sol 的具體順序（玩家操作、資源消耗、事件觸發、結果結算）：待平衡測試。
- Sol 10 觸發補給事件：水恢復至 100，食物恢復至 100。
- 補給事件是否顯示動畫、提示或一次性通知：待平衡測試。

## 11. 遊戲結束條件

1. **正常完成**：生存至 Sol 20。
2. **緊急中止**：關鍵生存資源耗盡且無法恢復。
3. **特殊結局**：探測車發現最高等級重大科研樣本。

關鍵資源的最低值、資源耗盡後的寬限時間與「無法恢復」判定：待平衡測試。

## 12. 最終結算

總分只根據地質樣本科研分數計算。成就勳章另行設計，不計入總分。

| 科研分數 | 稱號 |
| ---: | --- |
| 0–29 | 太空新手 |
| 30–69 | 小小太空人 |
| 70–119 | 火星探險家 |
| 120–179 | 超級小小太空人 |
| 180 以上 | 火星科學大師 |

成就勳章條件、顯示方式與是否可重玩解鎖：待平衡測試。

## 13. 介面與無障礙方向

- 手機優先，工作站使用大型可點擊區域。
- 資源同時以圖示、文字數值與血條顯示，不只依賴顏色。
- 重要事件與資源不足使用清楚、適合 7–12 歲玩家的文字。
- 桌機支援寬版排列，手機支援直向單欄排列。
- 具體色彩對比、字體尺寸、音效與鍵盤操作：待平衡測試／設計確認。
